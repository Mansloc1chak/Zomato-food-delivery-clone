# 🍕 Zomato Food Delivery Website Clone

A frontend website inspired by Zomato, built using HTML, CSS, and JavaScript. This project recreates the look and feel of a food delivery platform with a clean layout, restaurant listings, food categories, and a search feature.

## 📌 About the Project

The Zomato Food Delivery Website Clone is a beginner-friendly web development project created to practice frontend development skills. It features a food delivery homepage with restaurant cards, food categories, a search bar, and a responsive layout.

## ✨ Features

- 🏠 **Homepage:** Attractive hero section with a food background image.
- 🔍 **Search Functionality:** Search for restaurants and food items.
- 🍔 **Food Categories:** Browse categories such as Burger, Pizza, Noodles, Italian, Indian, and Barbecue.
- 🍽️ **Restaurant Listings:** Display restaurant names, ratings, prices, discounts, and estimated delivery times.
- 📱 **Responsive Design:** Layout adapts to different screen sizes.
- 🎨 **Interactive UI:** Hover effects on navigation links, food categories, and restaurant cards.
- 📲 **App Promotion Section:** A section showcasing the food delivery experience.
- 🔗 **Navigation:** Links to different sections of the website.
- 📄 **Footer:** Includes informational links and a project disclaimer.

## 🛠️ Technologies Used

- **HTML5** – Website structure and content.
- **CSS3** – Styling, layouts, hover effects, CSS Grid, Flexbox, and media queries.
- **JavaScript** – Basic restaurant search and filtering functionality.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Enter a food name, such as Pizza, Burger, Chinese, Indian, Grill, or Desserts, in the search box to test the search feature.
